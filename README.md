# 📊 Bybit Futures Screener

Скринер фьючерсного рынка **Bybit USDT.P** на основе двух авторских индикаторов с живым свечным графиком.

## 🚀 Быстрый старт

```bash
# Установить зависимости
npm install

# Запустить dev-сервер (http://localhost:5173)
npm run dev
```

## 📈 Индикаторы

Все расчёты — точный порт с Pine Script v6, оптимизированный под TS.

### ⚡ RF + СВГ (Range Filter)

Трейлинг-фильтр `EMA(EMA(|Δsrc|, per), per*2-1) × qty` с волнами Аллигатора.

- Линия красится посегментно: `#05ff9b` вверх / `#ff0583` вниз
- Челюсть Аллигатора вынесена в будущее (12 баров)
- **RF→Jaw** — расстояние до челюсти, 0% = касание (голубая вспышка)
- **СВГ** — свинг + длинный хвост + тренд Аллигатора

### 📊 CCI + Bollinger Bands

CCI с полосами Боллинджера поверх, дефолты: `Length 200 / MA 68 / StdDev 1.2`.

- **BB%** — позиция CCI относительно полос
- **±100%** — положение относительно уровней
- **X** — ход от MA к границе канала, «—» при выходе
- **BW** — ширина канала в пунктах CCI (стабильная метрика)
- **Импульс** — резкое расширение на сильном баре с объёмом

### 🌊 WaveTrend Cipher

`esa → de → ci → wt1(EMA) → wt2(SMA)` + MFI-область.

- Фрактальные дивергенции с подтверждением через 2 бара
- Линии строго между соседними холмами
- Угол дивергенции, OB/OS-зоны, точки кроссов

### 📈 DEMA 200

Double Exponential Moving Average: `DEMA = 2·EMA − EMA(EMA)`.

- фиолетовая линия на графике цены;
- цена выше DEMA → тренд вверх, покупка;
- цена ниже DEMA → тренд вниз, продажа;
- фильтры поиска «↑ выше» и «↓ ниже»;
- сколько баров цена держится по одну сторону и дистанция в %.

### 🌊 Elliott Wave

Порт LuxAlgo без линий Фибоначчи: ZigZag по пивотам, мотивные волны 12345, коррекции ABC.

- мотивная волна — W3 не наименьшая, пик 5 > пика 3, пик 3 > пика 1;
- коррекция ABC пунктиром после мотивной;
- точка возможной новой волны (1) — потенциальный разворот;
- маркер ✕ при пробое бокса коррекции;
- отдельный фильтр поиска и вес в скоринге.

### 📶 ADX / DMI

Стандартный ADX по Уайлдеру: `DI Length 14 / ADX Smoothing 14`, сигнальный уровень 20.

- жёлтая линия — ADX (сила движения);
- зелёная `+DI` и красная `−DI` определяют направление;
- сигнал возникает при переходе ADX снизу вверх через 20;
- LONG, если `+DI > −DI`, SHORT, если `−DI > +DI`;
- отдельный фильтр поиска **«Свежий ADX > 20»**, возраст сигнала и вес в скоринге.

### 🎯 Скоринг (0–100%)

Направление определяется голосованием, уверенность — суммой весов выполненных условий.

| Фактор | Вес по умолчанию |
| --- | --- |
| Направление RF | 14 |
| ★ Двойная метка RF | 18 |
| ★ RF пересёк челюсть | 16 |
| 🔥 Крест + CCI на том же баре | 24 |
| 🌊 Дивергенция WaveTrend | 16 |
| 📶 ADX выше 20 | 18 |
| Пробой BB | 10 |
| Импульсное расширение BB | 10 |
| СВГ сигнал | 10 |
| Свежий разворот RF | 8 |
| Зона ±100 | 8 |
| Касание челюсти | 6 |
| CCI × MA | 6 |

### 🔥 Сильные комбо-сигналы

1. **★ Двойная метка RF** — разворот диапазона + цена подтвердила
2. **✕ RF × Челюсть** — линия пересекла синий Аллигатор
3. **🔥 Крест + CCI** — пересечение челюсти и сигнал CCI на одном баре (самый сильный)

Все сигналы фильтруются по свежести: `maxBarsAgo = 1` бар (настраивается).

## ⚙️ Настройки

Кнопка **«Настройки»** открывает панель со всеми параметрами. Сохраняются в `localStorage` (ключ `bybit-screener-settings-v3`).

## 🔄 Живое обновление

Кнопка **LIVE** — период зависит от ТФ:

| ТФ | Интервал |
| --- | --- |
| 5m | 15 сек |
| 15m | 30 сек |
| 30m | 45 сек |
| 1h | 60 сек |
| 4h | 2 мин |
| 1d | 5 мин |

Позиция прокрутки не сбрасывается, если вы ушли в историю.

## 🖱 Управление графиком

- **Колесо мыши** — зум к позиции курсора
- **Перетаскивание** — панорама влево/вправо
- **Кроссхэйр** — цена и OHLC под курсором
- **Ручка между панелями** — изменение высоты окон

## 🛠 Разработка в VS Code

Полезные сочетания:

### Структура данных

```typescript
interface Analysis {
  symbol: string;
  price: number;
  dir: 1 | -1 | 0;        // направление
  score: number;           // 0..100 уверенность
  fresh: number;           // баров с триггера
  entry: number;           // точка входа
  stop: number;            // стоп-лосс
  tp1: number;             // тейк 1 (1.5R)
  tp2: number;             // тейк 2 (3R)
  rf: RFResult;            // Range Filter
  cc: CCIResult;           // CCI + BB
  wt: WTResult;            // WaveTrend
  candles: Candle[];       // сырые свечи
}
```

## ⚠️ Ограничения

- Публичный API Bybit: ~10 запросов/сек. При 500 монетах скан занимает ~1 минуту. Безопасная стартовая глубина — 100.
- CORS работает из браузера напрямую, но при блокировке региона может понадобиться VPN.
- Данные — не инвестиционная рекомендация.

## 🧯 Стабильность и память

Сетевой слой защищён от накопления фоновых задач:

- новый скан отменяет предыдущий через `AbortController`;
- активный скан можно остановить кнопкой **«Остановить»**;
- каждый запрос имеет таймаут 15 секунд;
- LIVE-режим выполняет только один запрос выбранного ТФ и не допускает перекрытия запросов;
- при скрытой вкладке LIVE-запросы приостанавливаются;
- изменение настроек пересчитывает загруженные свечи локально и не запускает новый скан 500 монет;
- кэш ограничен 60 записями и очищает просроченные данные;
- расчёт отдаёт браузеру управление каждые четыре монеты, чтобы интерфейс и сборщик мусора не блокировались.

Если VS Code потребляет слишком много памяти:

1. Выполни команду **Developer: Reload Window**.
2. Закрой старые вкладки браузера со скринером — оставь одну.
3. Запускай один `npm run dev`, не несколько терминалов одновременно.
4. В скринере начни со 100 монет, затем увеличивай глубину.

Настройки проекта уже отключают экспериментальную полную диагностику TypeScript, ограничивают TS Server до 1 ГБ и исключают
`node_modules`/`dist` из наблюдения VS Code.
